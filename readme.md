# Data-Structures-n-Algorithms
All the lab assignments on Data Structure Lab, PCL(CS)305

## Disclaimer
All the codes have been written in strictly C language. Some codes maybe buggy and only work in accordance to their respective Lab questions.

## Content
- Stack, Queue and Circular Queue implementation using array.
- Evaluation of Postfix expression using Stack.
- Linked List, Circular LL and Doubly LL implementation.
- Stack and Queue implementation using Linked List.
- Insertion, Selection and Bubble sort for integer arrays.
- Quick Sort, Heap Sort and Merge Sort implementation.
- Insert method implementation and inorder traversal of a Binary Search Tree(BST).
